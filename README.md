# Project Twitter Bila

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E?logo=javascript&logoColor=black) ![Vite](https://img.shields.io/badge/Vite-bundler-646CFF?logo=vite&logoColor=white) ![HTML5](https://img.shields.io/badge/HTML5-CSS3-E34F26?logo=html5&logoColor=white) ![Licença](https://img.shields.io/badge/licença-MIT-green)

Clone temático do Twitter/X dedicado à Bila (poodle branco). Feed interativo com posts, likes, retweets e replies.

## Funcionalidades

- Feed de posts com fotos e vídeos da Bila
- Interações: like, retweet e reply
- Layout responsivo inspirado no Twitter/X
- Ícones via Font Awesome

## Stack

- HTML5 + CSS3
- JavaScript vanilla
- Vite (bundler)
- Google Fonts (Roboto)

## Instalação

```bash
git clone https://github.com/ooshimakenji/project-twitter-bila.git
cd project-twitter-bila
npm install
npm run dev
```
